Executive Project Summary

RestartHER is an enterprise-grade inclusive workforce platform designed to neutralize algorithmic resume-gap biases for women returning to tech after career breaks (maternity, caregiving, health). Powered by Google Gemini AI and SAP Cloud Application Programming Model (CAP) conventions, the system automatically evaluates past competencies against enterprise roles, calculates missing skill deltas, pairs candidates with SAP LMS bridges, connects returners with executive mentors via instant Google Meet sessions, and audits enterprise candidate pipelines for career-break equity.

RestartHER Architecture Specification Section 2 · Core Module Engineering

⚙️ 2. Core Module Engineering

2.1 AI Skills Discovery & Gap Analysis Engine (srv/career-service.js)

The Skills Discovery Engine ingests unstructured text detailing candidate background, tenure, and pause reasons. It queries Google Gemini AI using structured system instructions that enforce returning candidates' caregiving experience to be interpreted as executive leadership qualities.

Skills Delta Mathematical Model:

Given past verified proficiency $P_{\text{past}} \in [0, 100]$ and role benchmark $P_{\text{target}} \in [0, 100]$, the gap delta is evaluated as: $$\Delta_{\text{gap}} = \max(0, P_{\text{target}} - P_{\text{past}})$$ If $\Delta_{\text{gap}} \le 5\%$, the skill is flagged as ✓ Retained & Ready. If $\Delta_{\text{gap}} > 5\%$, the system queries the SAP Learning Hub LMS catalog to attach an actionable micro-course bridge. 

// Gemini AI Invocation Prompt Snippet (srv/career-service.js)
const prompt = `
You are an expert Executive Career Architect & SAP SuccessFactors Talent Specialist.
A woman professional is returning to the workforce after a career break.
Analyze her past experience and compare it against target role: "${targetRole}".
Evaluate career break superpowers: crisis management, emotional intelligence, resilience.
Return JSON with: candidateName, overallReadinessScore, careerBreakAnalysis, skillDeltas.
Each skillDelta must specify: skill, category, pastProficiency, requiredProficiency, 
gapDelta, actionableBridge, sapLmsCourse.`;

2.2 Executive Mentorship & Dynamic Google Meet Scheduler

RestartHER eliminates the scheduling friction that often intimidates returners. Candidates select an executive mentor (e.g., Dr. Ananya Roy, VP of Engineering at SAP) and choose an open slot. The Node.js backend handles meeting initialization:

Instant Meet Protocol (/api/generate-meet-link):
  1. Validates candidate authorization and mentor availability.
  2. Generates a dynamic Google Meet room code (e.g. https://meet.google.com/xxx-yyyy-zzz).
  3. Persists the session to the local SQLite/JSON datastore (restarther-data.json).
  4. Syncs the session to the Mentor's Active Mentee queue in real time.

2.3 Enterprise AI Bias Audit Engine (srv/audit-service.js)

To ensure partner enterprises evaluate returners objectively, the system conducts automated pipeline bias audits. It simulates screening resumes under two conditions: (1) with visible career gap duration, and (2) with the gap dates anonymized and evaluated strictly on foundational competency.

RestartHER Architecture Specification Section 3 · Enterprise Integration & Data Schema

🌐 3. SAP BTP Connectors & CDS Data Schema

RestartHER adheres to SAP enterprise integration patterns, exposing OData V4 compliant endpoints and CDS entity definitions.

3.1 Core CDS Schema Definition (db/schema.cds)

namespace restarther.db;

using { cuid, managed } from '@sap/cds/common';

entity Candidates : cuid, managed {
    name                : String(100);
    email               : String(120);
    preBreakRole        : String(150);
    preBreakTenureYears : Decimal(4,1);
    breakDurationYears  : Decimal(4,1);
    breakReasonCategory : String(100);
    compositeReadiness  : Integer;
    targetRole          : String(150);
    status              : String(30);
    skills              : Composition of many Skills on skills.candidate = $self;
    sessions            : Association to many MeetSessions on sessions.candidate = $self;
}

entity Skills : cuid {
    candidate           : Association to Candidates;
    skillName           : String(100);
    category            : String(50);
    pastProficiency     : Integer;
    requiredProficiency : Integer;
    gapDelta            : Integer;
    lmsBridgeCourse     : String(200);
}

entity MeetSessions : cuid, managed {
    candidate           : Association to Candidates;
    mentorName          : String(100);
    mentorRole          : String(150);
    meetUrl             : String(255);
    googleMeetId        : String(50);
    scheduledSlot       : String(100);
    status              : String(30);
}
